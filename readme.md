# OpsPilot — Project Management Dashboard

OpsPilot is a project management and operations dashboard designed to help teams organize projects, track tasks, monitor progress, and improve productivity.

The goal of this project is to build a practical software product while developing strong frontend and backend engineering skills.

## Current Features

- Dashboard layout and sidebar navigation
- Custom branding and warm minimalist design system
- Responsive layout foundation

## Tech Stack

- HTML5 — Semantic page structure
- CSS3 — Layout, styling and responsive design
- JavaScript — Interactive functionality (in development)

## Project Structure

```text
OpsPilot/

```

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
